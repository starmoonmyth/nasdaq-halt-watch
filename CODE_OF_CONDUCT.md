# Contributor Covenant Code of Conduct

We want this project to be welcoming, constructive, and safe for everyone.
Participants must act professionally, assume good faith, give actionable
feedback, and avoid harassment, discrimination, personal attacks, or doxxing.

Maintainers may remove comments, close issues, or restrict participation when
conduct violates this code. Report concerns privately to the maintainers via
the contact listed in the repository profile.
